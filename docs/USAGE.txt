C 盘清理助手 (Cleaner) 使用说明
================================

版本：2.0.2
适用系统：Windows 10 / Windows 11（64 位或 32 位）
不需要安装 .NET 运行时，程序为单文件原生应用。

一、快速开始
------------
1. 双击桌面上的「C 盘清理助手」图标，或从开始菜单启动。
2. 程序启动后会自动扫描各清理项目占用的大小（可随时点击「重新扫描」）。
3. 勾选想要清理的项目（默认已勾选安全的常用项）。
4. 点击「立即清理」，确认后即可释放空间。

二、清理项目说明
----------------
默认勾选（无需管理员权限）：

  用户临时文件         Windows 与应用产生的临时文件
  浏览器缓存           Edge / Chrome / Brave / Vivaldi / Opera / Firefox 的网页缓存
  崩溃转储与错误报告   应用崩溃转储与 Windows 错误报告存档
  显卡着色器缓存       D3DSCache、NVIDIA / AMD / Intel 着色器缓存

可选（默认不勾选）：

  缩略图与图标缓存     资源管理器缩略图数据库，删除后自动重建
  开发工具缓存         npm、pip、Yarn、Electron、NuGet 的下载缓存
  回收站               清空回收站，清空后无法恢复

需要管理员权限（在程序内点击「以管理员身份重启」后可用）：

  Windows 临时文件     系统级临时目录
  系统错误报告与转储   系统级 WER 存档、内核报告、内存转储
  Windows 更新缓存     已下载的更新安装包与传递优化缓存
  旧系统安装残留       Windows.old 等升级残留，通常可释放数 GB

三、安全边界
------------
程序只处理上面列出的白名单目录，并且：

  · 从不触碰桌面、文档、下载、图片、音乐、视频；
  · 不清理浏览器书签、密码、历史记录与 Cookie；
  · 跳过符号链接 / 目录联接，不会顺着链接删到别处；
  · 跳过正在使用的文件，并在日志中记录；
  · 清理的是目录内容，缓存目录本身会保留。

四、关机时自动清理
------------------
在界面底部勾选「关机时自动清理已勾选项目」并确认后，程序会创建一个名为
Cleaner_AutoClean 的计划任务：

  · 在关机 / 重启时触发，以当前用户身份运行；
  · 若关机流程提前结束，会在下次登录 2 分钟后补做一次；
  · 只清理勾选的项目，系统级项目不会在自动清理中执行。

取消勾选即可删除该计划任务。

五、设置与日志
--------------
设置：%LOCALAPPDATA%\Cleaner\settings.json
日志：%LOCALAPPDATA%\Cleaner\logs\clean-*.log（保留 30 天，可自动清理）

在程序右下角「更多」菜单中可以打开日志目录，也可以切换界面语言
（简体中文 / English）。

六、命令行
----------
Cleaner.exe                      启动图形界面
Cleaner.exe --selftest           运行内置自检（20 项检查）
Cleaner.exe --dry-run            只统计不删除，输出每个项目的目标路径
Cleaner.exe --clean <ids>        命令行清理指定项目，例如 --clean userTemp,browserCache
Cleaner.exe --scheduled          执行关机自动清理（计划任务调用）
Cleaner.exe --uninstall-auto     删除自动清理计划任务

七、卸载
--------
在「设置 → 应用 → 已安装的应用」中找到「C 盘清理助手 (Cleaner)」并卸载，
或从开始菜单的 Cleaner 程序组里运行「卸载 C 盘清理助手」。

卸载时可选择同时删除设置与日志。
