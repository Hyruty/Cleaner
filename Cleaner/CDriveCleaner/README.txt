C盘清理助手
============

使用方法
--------
1. 双击 Start-CDriveCleaner.cmd。
2. 程序会先扫描列表中各项缓存的大致占用。
3. 取消勾选不想清理的项目，然后点击“立即清理”。
4. 如需关机时自动清理，勾选“每天关机时自动清理已勾选项目”。

安全范围
--------
程序只处理界面中列出的白名单目录：

- 当前用户临时文件
- Edge / Chrome 的网页缓存
- 当前用户崩溃转储与错误报告
- 显卡着色器缓存
- Windows 临时文件（可选，需管理员）
- Windows 系统错误报告（可选，需管理员）
- Windows 更新下载缓存（可选，需管理员）
- 回收站（可选，默认不勾选，清空后不可恢复）

程序不会扫描或删除：

- 桌面、文档、下载、图片、音乐、视频
- 浏览器书签、密码、历史记录、Cookie
- 普通安装程序、游戏和文档
- 正在使用的文件

自动清理说明
------------
启用后，程序会在 Windows 关机事件触发时运行；如果关机流程提前结束任务，
会在下次登录 2 分钟后补做一次。自动任务以当前用户权限运行，因此只清理
不需要管理员权限的项目。

日志位置
--------
%LOCALAPPDATA%\CDriveCleaner\logs

卸载自动任务
------------
双击 Remove-AutoClean.cmd，或在程序中取消勾选自动清理。
